# Quick Audio Recorder 中文说明

[English](README.md)

Quick Audio Recorder 是一款运行在 **Windows** 系统托盘中的轻量级录音工具，支持麦克风、系统声音（Loopback）和两者混合录音。可以用托盘图标或全局快捷键快速开始、停止录音。

## 主要功能

- **麦克风录音**：只录制麦克风输入。
- **系统声音录音**：录制电脑播放的声音。
- **混合录音**：将麦克风和系统声音合成为同一个录音文件。
- **输出格式**：MP3 或 WAV。
- **全局快捷键**：分别指定录制麦克风、系统声音、混合声音与停止录音的快捷键。
- **音量标准化**：录音结束后按需要自动调整音量。
- **剪贴板**：可将录音文件复制到剪贴板，或在复制前移动到系统临时文件夹。

## 如何使用

1. 启动软件，右下角系统托盘会出现录音图标。
2. **右键单击**托盘图标，选择「设置」。
3. 选择麦克风、录音保存位置和输出格式。
4. 按需设置全局快捷键、左键单击操作及录音后的处理方式。
5. **左键单击**托盘图标或使用快捷键开始录音；再次单击或使用停止快捷键即可结束。

## 开机自启动与设置卡死修复

在「设置」中勾选「登录 Windows 时自动启动」，点击「保存设置」，软件就会在当前 Windows 用户登录时自动运行并显示在系统托盘中。取消勾选后保存即可关闭。默认关闭，无须管理员权限，也不会创建系统计划任务。请将 EXE 放到长期存放的位置后再开启，移动 EXE 后需要重新保存此选项以更新路径。

原有设置会自动迁移到用户目录 `%APPDATA%\\QuickAudioRecorder\\settings.json`，避免开机启动时因工作目录不同而找不到设置。保存设置已改为非模态提示；设备刷新和快捷键注册在后台执行。

## 设置界面语言

在「设置」顶部的语言下拉框选择：

- **跟随系统**：Windows 为中文时使用简体中文，其他语言默认使用英文。
- **简体中文**：始终使用简体中文界面。
- **English**：始终使用英文界面。

保存后**退出并重新启动软件**即可切换界面语言。旧版 `settings.json` 中的英文托盘模式值会自动兼容，不会修改录音文件或快捷键配置。

注意：麦克风名称、文件名、技术异常的原始信息等可能沿用系统语言或英文。语言切换不影响录音内容。

## 运行与打包

需要 Python 3.12 及以下依赖：

```powershell
pip install PyQt6 soundcard soundfile numpy lameenc keyboard
python main.py
```

打包为单文件 EXE：

```powershell
pip install pyinstaller
pyinstaller --noconsole --onefile --name QuickAudioRecorder main.py
```

生成的程序位于 `dist/QuickAudioRecorder.exe`。

## 浏览文件夹或刷新设备时卡死的诊断版修复

为避免 Windows 系统调用造成界面永久“未响应”，当前测试版做了以下改变：

- **浏览文件夹**：使用 Qt 自带（非原生）目录选择器；也可以直接在文件夹路径输入框粘贴路径，无须打开选择器。
- **刷新设备**：在独立子进程中调用 WASAPI 枚举。扫描过程可点击「取消扫描」，默认 15 秒超时（打包为单文件 EXE 时需要给子进程启动留出时间）。超时或失败时保留原设备列表。
- **卡死日志**：记录打开选择器、刷新设备、超时等事件。主界面心跳连续 8 秒没有更新时，会尝试保存所有 Python 线程的堆栈。

**日志位置：** `%LOCALAPPDATA%\QuickAudioRecorder\Logs\`

- `app.log`：运行、扫描和异常事件（文件大小达到阈值会轮换）。
- `hang-stacks.log`：Python 线程堆栈，可帮助定位卡在什么调用。

如果依然未响应，请关闭程序后将这两个日志文件发给开发者。发送前请检查并遮盖其中可能涉及设备名称、用户路径或其他私人信息。原生音频驱动阻塞时，Python 堆栈可能不够，需要进一步通过 Windows 进程转储分析。

**测试建议：** 确认旧版已退出，再运行最新测试版；依次测试浏览目录、粘贴路径、刷新设备、取消扫描、超时后的界面响应、正常录音与热键。不建议在未验证前合并到主分支。
